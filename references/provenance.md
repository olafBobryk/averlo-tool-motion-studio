# Provenance and public package scope

Motion Studio packages Averlo-authored Three.js/Remotion mechanisms and user-directed motion: spatial absorption, studio materials and analytical shadows, choreography adapters, and deterministic geometry/visibility gates. The historical V15 choreography is preserved as a source reference, not an endorsed final film or a required sequence. Reusable implementation lives in `assets/starter`.

No client artwork, client footage, external reel footage, private test films, machine paths, or local-only video references are included. The duplicated archival source snapshot was excluded: its renderer embedded an external video and a client composition name; all reusable mechanisms are available in the portable starter.

`assets/sample` contains original generic FORM / SPACE / MOTION SVG panels and PNG exports created by Averlo for this public package, with no client imagery. These are covered by the root Averlo Tool Use Terms. They are technical sample inputs, not evidence of approval for an earlier creative film.

Adapted motion-direction concepts: https://skills.sh/iart-ai/motion-design-skills/motion-art-direction (local reference version0.1.0), MIT Copyright2026 iart.ai. Incorporated shared easing vocabulary, deliberate rhythm, motion hierarchy, consistency checks; rewritten around continuous overlap. Excluded fixed mandatory stillness and generic presets. Full notice: licenses/motion-design-skills.txt.

Spatial-reference concepts: https://skills.sh/liamrjohnston/remotion-motion-graphics-skill/cinematic-camera, MIT Copyright2026 Promptible. Incorporated coherent coordinates, reference inspection and continuous transformation. Excluded warm-background fallback, mandatory intake and prescribed camera/choreography. Full notice: licenses/remotion-motion-graphics-skill.txt.

Three.js area-light limitation verified against https://threejs.org/docs/pages/RectAreaLight.html. Dependencies retain their own licenses; a package install is not a license transfer for supplied artwork.
